개인정보 처리방침

개발자: bangcepslabs · 시행일: 2026-11-13

1. 처리하는 정보와 목적

CaptureSok은 사용자가 캡처를 실행한 탭의 화면을 이미지로 만듭니다. 화면에 개인정보가 표시되어 있으면 그 내용도 이미지에 포함될 수 있습니다. 영역 선택에는 페이지 요소의 위치와 크기를 사용하고, 전체 페이지 캡처에는 페이지 크기와 스크롤 위치를 사용합니다. 캡처 중에는 원래 탭인지 확인하기 위해 탭 ID와 URL을 일시적으로 처리합니다.

2. 기기 안에서의 처리

이미지와 페이지 정보는 브라우저 안에서만 처리합니다. 개발자 서버로 업로드하거나 제3자에게 전송하지 않습니다. 계정, 광고, 분석 SDK, 추적 코드를 사용하지 않습니다. 파일 저장과 클립보드 복사는 사용자가 선택한 기능에 따라 Chrome과 운영체제를 통해 이루어집니다.

3. 저장과 삭제

파일 형식, JPG 품질, 테마, 미리보기, 자동 저장, 마지막 캡처 모드는 브라우저의 로컬 저장소에 보관합니다. 캡처 작업 상태는 브라우저 세션 저장소에 일시 보관하고 작업 종료 시 지웁니다. 캡처 이미지는 확장 프로그램의 IndexedDB에 임시 보관해 결과 화면의 새로고침을 지원합니다. 결과 화면에서 이미지 삭제를 누르거나 결과 탭을 닫으면 임시 이미지를 삭제합니다. 비정상 종료로 남은 이미지는 생성 후 24시간이 지나면 다음 이미지 조회 또는 저장 시 정리합니다. 이미 다운로드한 파일과 시스템 클립보드는 확장 프로그램이 삭제하지 않습니다.

4. Permissions

activeTab and scripting support user-requested capture. storage keeps local settings and temporary state. downloads saves images. No persistent website access is requested.

5. 이용자의 선택

ESC 또는 팝업의 취소 버튼으로 캡처를 취소할 수 있습니다. 저장·미리보기 옵션은 설정에서 변경할 수 있습니다. Chrome 단축키 관리 화면에서 각 기능의 키를 변경하거나 해제할 수 있습니다. 확장 프로그램을 제거하면 확장 프로그램의 로컬 데이터도 제거됩니다.

CaptureSok Privacy Policy

Developer: bangcepslabs · Effective: 2026-11-13

Information used

When you start a capture, CaptureSok processes the current tab's pixels, element geometry, page dimensions and scroll position. Screenshots may contain personal information visible on the page. A tab ID and URL are held temporarily to verify that the correct tab is being captured.

Local processing

Images and page information are processed inside your browser. They are not uploaded to developer servers or shared with third parties. CaptureSok has no accounts, advertising, analytics SDKs or tracking. Saving files and copying images use Chrome and your operating system when you choose those features.

Storage and deletion

Preferences and the last capture mode are stored locally. Capture job metadata is held in session storage and removed after the job ends. Images are temporarily stored in extension IndexedDB so previews can reload. Deleting an image in the preview or closing its tab removes the temporary record. Records left by abnormal termination become eligible for cleanup after 24 hours and are removed during the next image lookup or save. Downloaded files and the system clipboard are not erased by the extension.

Permissions

activeTab and scripting support user-requested capture. storage keeps local settings and temporary state. downloads saves images. No persistent website access is requested.

Limited Use and contact

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Contact: bum2432@gmail.com.
